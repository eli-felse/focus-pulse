# Focus Pulse

Focus Pulse lets you log how many minutes you spent on a task, rate your mood on a -3 to +3 slider, and add an optional note. It shows today's totals and a 7-day mood trend line chart, with everything stored privately in your browser so there are no accounts, logins, or servers involved.

**Tags:** html, css, javascript
